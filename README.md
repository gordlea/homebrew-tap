# gordlea/homebrew-tap

Homebrew formulae for [Gord Lea](https://github.com/gordlea)'s tools.

```sh
brew install gordlea/tap/term-boss
```

| Formula | What it is |
|---|---|
| [`term-boss`](Formula/term-boss.rb) | Theme your terminal per directory: tab colour and name, badge and colour scheme from `.term-boss.toml` files. [Source](https://github.com/gordlea/term-boss). |

`Formula/term-boss.rb` is written by term-boss's release workflow on every release, with
prebuilt binaries for macOS and Linux on x86_64 and aarch64. `brew upgrade` picks up new
versions.
